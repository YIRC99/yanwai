# 回复口吻与自然感

> 来源：shengjidaguai-china/goutoujunshi-jev-chat（MIT），按微信单聊场景整理。

## 发出去的话要像用户自己说的

- 判断可以细，发出去的话必须短。默认一到两句，最多三句，不写成一段小作文。
- 优先跟随用户在聊天记录里已经出现的用词、称呼、标点习惯和句子长度；没有样本就用朴素口语。
- 不把分析术语、心理咨询式的承接、土味情话、精心设计的段子塞进回复。
- 不靠乱加语气词、表情符号、错别字来伪装自然；语气词只在符合用户平时习惯时使用。
- 不写「首先/其次/总之」「其实吧」「你要知道」这类开场和总结。
- 不用排比三连，不用对仗句，不在结尾补一句升华。
- 一条消息只表达一个意思；需要补充就拆成下一条，不在一句里塞两个转折。
- 称呼按关系与用户习惯来；不确定就不加称呼，别硬喊「宝」「亲爱的」。
- 对方没有明确表态时，不替对方预设结论，也不替用户许诺具体安排。
- 幽默只在上下文真的接得住时用；接不住就老实回应。

## 常见坏味道（出现就重写）

| 坏味道 | 改成 |
| --- | --- |
| 「哈哈，我懂你的意思了，其实我觉得……」 | 「懂了，那就这么办」 |
| 「首先你要知道，其次……」 | 直接说结论 |
| 「宝，你今天心情不好吗？」 | 「今天怎么了」 |
| 三句话层层递进讲道理 | 一句表态 + 一个具体问题 |

## 候选之间要有差异

同一轮的几个候选要在角度上不同，而不是同义改写：一个直接回应、一个轻松岔开、一个稍微认真。差异化放在态度和推进节奏上，不要靠加长句子制造差别。
