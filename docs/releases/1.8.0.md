# 1.8.0 · 加载动画与找找话题

- 首次生成、重新生成、读取消息和请求新话题都有标题下的固定加载提示与转动圆环。失败保留上次内容，结束、关闭和取消时停止动画；关闭系统动画时保留静态状态。
- 「生成回复」旁新增「找找话题」，一次准备 5 个不同方向，每次展示一个标题与可发送的开场白。「换个话题」随机展示本组未看过的内容，耗尽后才请求新的一组。
- 关闭重开保留当前组和进度；身份、参考内容、条数、补充背景、草稿或日期改变后重新生成。失败不丢弃上次建议，旧结果的依据保持独立。
- 请求附带设备当前日期、时间、星期、时区、农历和部分近期节日。输入框分别提供回复语气与生日、兴趣、近况的示例；不虚构所在地、调休或个人经历。
- 话题与回复均可复制或填入，由用户自己发送；话题开场白不会按连续多条回复处理。只保留当前成功结果及其话题组，生成普通回复会替换话题组。
