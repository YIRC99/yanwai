# 言外 v2.1.7｜智能分析、彩色情绪圆环，引用回复也能分析

这一轮更新，让聊天解读更细，也更少占用聊天页面。以下汇总 2.1 系列的主要变化。

## 意图分析，两种方式自己选

- **JEV 决策模型**：从内置选项中快速判断，沿用原有分析方式。
- **智能分析**：使用你配置的通用大模型，结合前文解读意图、可能在意的点和情绪倾向；优先用短句，不生成回应建议。

两条线路的情绪概率都由 JEV 提供。智能分析会先显示情绪，再补充解读；解读失败时保留情绪，点击卡片即可重试。智能分析通常等待更久，也可能误读，结果仅供参考。

## 卡片更紧凑，也能透出聊天壁纸

- 情绪改用**彩色小圆环**：每种情绪固定配色，环内显示百分比，旁边保留名称。
- **0% 的情绪自动隐藏**，不留空位；非零小概率保留为 `<1%`。
- 去掉横向概率条、段落空行和冗长说明，收紧行距与留白，结尾只保留「仅供参考」。
- 保留深色半透明底、细边框和背景模糊；无法采样背景时使用半透明样式。
- 首行统一为 `yanwai 2.1.7`，两条分析线路使用相同卡片样式。

## 修复滚动时反复收起、重新弹出

- 新版聊天列表中，消息暂时离屏时保留卡片，重新出现时及时恢复。
- 同一聊天里已经开始的分析可以完成并缓存，滚回来复用结果。
- 加载更多历史不会仅因前文范围变化就重复分析同一条消息。
- 切换聊天、离开页面、关闭分析或修改模型配置时，仍会取消相关请求，避免旧结果混入。

## 引用后的文字回复，也能触发分析

支持对方引用消息后发送的文字回复，自动分析和长按「翻译意图」都可使用。

分析以**本次回复正文**为目标，被引用的文字单独作为依据，避免混淆双方的话。引用的是图片、文件或不可读内容时，仍可分析新回复，不会假装理解引用附件；普通链接、文件卡片仍不触发分析。

## 设置更清楚，回复只保留复制

- 设置分为「聊天分析 / 回复建议 / 关于言外」，按所选线路显示需要的配置。
- 选择智能分析时才展开其供应商、Key 和模型设置；JEV 情绪连接与智能分析连接分别检测。
- 意图模型配置与「帮我回」独立保存。选择智能分析后，消息及相关前文会用于 JEV 情绪判断和所选模型解读，服务可能分别计费。
- **移除「直接填入聊天框」和「撤销填入」**。「帮我回」与「找找话题」只提供复制，由你自行粘贴、检查并发送。

## 安装与升级

1. 使用与旧版本签名一致的 APK 覆盖安装。
2. 确认 LSPosed / Xposed 已启用言外，作用域包含微信。
3. **彻底退出并重新打开微信**，加载新版本。
4. 想体验智能分析，在「聊天分析」选择该线路，填写配置并保存、检测；继续使用 JEV 无需新增配置。

需要 Android 9+ 和可用的 LSPosed / Xposed 环境。各聊天自动分析仍默认关闭，长按单条分析不会开启整个聊天的自动分析。

版本：**2.1.7 / versionCode 40**。离线测试和构建记录见仓库 `docs/VERIFY.md`；具体模型解读与宿主兼容性以实际设备体验为准。

言外免费开源，第三方模型服务按各自规则收费。
