# 2.1.9 · 分析缓存持久化

- 修复关闭分析、切换联系人再返回后，因页面历史范围变化而重复请求模型的问题。
- 完整分析结果和当次分析依据保存到言外应用自己的私有 SQLite 缓存；不在 wx 目录新增分析缓存文件，不修改聊天数据库。
- 按账号、联系人、目标消息和分析配置隔离；再次打开分析或重启 wx 后，可读取已保存的结果。账号无法核对或设置桥不可用时降级为内存缓存，并记录原因。
- 保留最多 5000 条、有效内容最多 32 MiB，超限按最近使用顺序清理。卸载言外或清除言外数据会删除缓存；普通升级保留缓存，恢复卡片时显示当前运行版本。
- 关闭开关仍隐藏卡片、取消任务并清除手动选择，但不删除已完成结果。未完成或意图失败的结果不作为持久化成功缓存。

## 手机验收

覆盖安装后打开言外一次，再彻底重启 wx。选择一个联系人，打开分析并等待完整结果，关闭开关，切换另一联系人操作，再返回打开；同一消息应复用结果。随后彻底重启 wx 再试一次。诊断日志中的 `ANALYSIS_CACHE_SAVED` 和 `ANALYSIS_CACHE_HIT` 分别表示已落盘和已读取；`ANALYSIS_CACHE_ACCOUNT_UNVERIFIED` / `ANALYSIS_CACHE_BRIDGE_FAILED` 表示这次只能使用内存缓存。

升级前仅存于内存的结果无法迁移；本版本首次完整分析后开始保存。实机交互由用户验收，离线测试不等于特定 wx 版本上的验证。
