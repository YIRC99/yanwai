# 1.7.2 · 选择参考条数后读取聊天历史

- 「选择对方身份」和「参考最近 N 条」放在同一行，去掉重复标签和常驻页面消息说明。
- 支持选择最近 30、50、100 条文字消息，首次默认 100 条。打开或切换条数后自动读取本机历史，用户再点击生成；读取期间不可生成，切换身份不会调用模型。
- 读取不足或只能使用页面消息时显示实际条数和原因，不把所选上限当成已读数量。条数菜单可查看已读取内容或重试；旧建议保留自己的原始依据。
- 支持当前页面只有媒体消息时核对历史；媒体内容、身份核对摘要均不发送给模型。保留会话隔离、快速切换取消、草稿保护和用户手动发送。
