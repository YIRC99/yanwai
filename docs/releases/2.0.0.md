# 2.0.0 · 语音也能理解

- 自动分析和单条「翻译意图」支持对方语音：先用微信原生能力转文字，再分析意图和情绪。
- 分析前文、回复建议和找话题纳入双方语音；回复的 30/50/100 条范围包含屏幕外的本机历史语音。
- 共用已有转写，显示准备进度；分析卡和回复依据可查看转写正文。失败语音标注缺口，目标语音失败不分析，全无可用内容不生成。
- 切换聊天或关闭功能时停止本次等待及后续模型调用。无需新增语音模型或 Key，原始音频不发给分析或回复模型。

转写只能反映文字内容，不能还原哭腔、音调等声音特征。原生兼容性已核对微信 8.0.71 安装包；手机转写及界面交互仍由用户验收。详见[语音支持与验收步骤](../VOICE_SUPPORT.md)。
