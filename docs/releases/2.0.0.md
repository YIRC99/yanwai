# 言外 v2.0.0｜语音也能理解，回复和话题一起帮你想

言外 2.0 来了。这一轮把「理解对方」「想好回复」「继续聊下去」放进了同一个微信聊天流程：文字和语音都能参与分析，回复可以参考双方前文，也能根据关系和近况找一个接得上的新话题。

下面汇总这一轮迭代截至 2.0.0 的主要变化，包含此前 1.x 小版本逐步加入的能力。

## 🎙️ 语音自动转写，分析和回复都能用

- 开启聊天右上角「分析」，或长按对方语音「翻译意图」，会先调用微信原生转文字，再分析情绪与意图。
- 分析前文、「帮我回」和「找找话题」参考范围内的双方语音，也会自动准备转写，包含回复所需的本机历史语音。
- 已有转写直接复用，无需额外配置语音模型或 Key。准备时有进度提示，分析卡和回复依据中可以核对转写正文。
- 转写失败会明确标注：目标语音失败时不继续分析，前文中的失败语音保留缺口；全部没有可用内容时不生成回复。

分析依据是转写文字，不包含音调、哭腔、语速等声音特征，也不把图片、视频和文件正文当作已经理解。

## 💬「帮我回」：参考聊天，给出自然的分条回复

在微信聊天「＋」面板打开「帮我回」，选择关系、参考范围，再写一点自己的想法，就能手动生成回复。

- **参考最近 30 / 50 / 100 条**：首次默认 100 条，文字与语音合计；自动读取当前聊天的本机历史，不需要先手动翻页。
- **关系由你决定**：支持暗恋对象、暧昧对象、恋人、朋友、长辈、家人、同事等，也可以不指定；「自定义身份」可填写前同事、相亲对象等背景。
- **回复按语意分条**：一组建议包含 1–6 条短消息，可以先回应，再补充具体内容。它们是依次发送的一组话，不是多个备选答案。
- **逐条复制、填入**：选中一句再操作，由你自己发送；不会覆盖输入框里尚未发送或清空的内容。
- **重开可以继续**：保留当前微信进程内上次成功建议及身份，填入后再次打开可继续下一条；微信进程结束后清空。
- **依据看得见**：「查看已读取」核对准备内容，「查看依据」核对当前建议真正使用的消息、时间、说话人和来源。历史不足会显示实际数量，不把 100 条上限当作已读取数量。

新消息不会自动触发回复生成。想更新上下文时重新读取，再由你点击生成。

## 💡「找找话题」：一次准备五个方向，慢慢选

不知道接下来聊什么，可以点「生成回复」旁的「找找话题」。

- 根据当前聊天、对方身份和补充想法，一次准备 **5 个不同话题**。
- 每个话题用 **1–3 句口语短消息**呈现，理由按需展开，也能逐句复制或填入。
- 「换个话题」先在本组未看过的内容中切换，全部看完后才请求新的一组，减少重复调用。
- 参考当前日期、时间、星期及近期节日；你也可以补充生日、兴趣和近况。不会把实时天气、热点或对方休假当成已知事实。
- 身份、参考内容或补充想法变化后，需要重新生成，避免把旧建议套到新背景上。

## 🧠 情绪与意图分析更细，也更重视上下文

- 情绪概率、交流意图和具体场景分别判断，覆盖确认信息、拒绝、道歉、感谢、澄清等常见表达。
- 43 套分析卡扩充日常场景与焦虑、困惑、疲惫等表达；第二轮复核情绪、意图及建议前提，明确暂停或拒绝时不继续劝说。
- 参考目标之前最多 24 条页面文字或语音，保留发送时间与间隔，不引用目标之后的内容。
- 继续支持各聊天独立开关与本地记忆；长按单条「翻译意图」不会打开整段聊天的自动分析。

## ⚙️ 模型配置与微信入口更完整

- 设置页分为「情绪判断 / 回复建议 / 关于言外」，两套模型配置独立。只用「帮我回」可以只配置回复模型。
- 情绪判断支持 Jev 官方 TypeSafe、OpenRouter、Vercel AI Gateway 及 Jev 兼容接口。
- 回复和找话题支持豆包、小米 MiMo、DeepSeek、OpenAI GPT、智谱 GLM、Kimi，以及自定义 OpenAI 兼容接口。
- 支持获取、筛选模型列表，也可手动填写模型 ID；不同供应商的地址、Key、模型分别保存。
- 微信「我 → 设置」增加插件分组里的「言外设置」原生入口，桌面应用和聊天长按入口继续可用。
- 读取上下文、生成回复、重新生成和找话题都有明确的加载状态；切换聊天或关闭面板会取消未完成请求。

## 安装与升级

1. 安装本次发布附件中的 APK。已有用户请覆盖安装；维护者分发时应沿用原安装包签名。
2. 在 LSPosed / Xposed 中启用言外，作用域选择微信。
3. 打开言外，按需要配置「情绪判断」或「回复建议」；回复需要开启手动生成许可并保存。
4. **彻底退出并重新打开微信**，让新版本加载。
5. 在聊天里开启「分析」体验语音分析，或从「＋」面板打开「帮我回」。无需开启自动分析也能使用回复和话题。

需要 Android 9+ 与可用的 LSPosed / Xposed 环境。已核对的宿主为微信 8.0.71，不承诺其他版本全部兼容。

## 数据边界与验证

- 言外不会自动发送消息。情绪分析在你开启当前聊天或手动选择单条后请求模型；回复和话题只在点击生成时把准备好的内容发送给所选模型服务商。
- 打开「帮我回」准备语音上下文时，就可能触发微信原生转写并联网；原始音频不发送给情绪或回复模型。微信自己的转写任务和结果由微信管理。
- 言外不额外持久化聊天原文或转写正文，缓存保留在进程内；API Key 保存在本机设置中，APK 不携带个人 Key。
- 2.0.0（versionCode 31）的 246 项离线测试通过，Debug 构建成功，已覆盖安装并核对手机版本。用户提供了上述实机截图，但这不等于所有兼容和异常场景都已完成测试。

言外免费开源，第三方模型可能按各自规则收费。分析与建议只是沟通辅助，不代表对方的真实想法。
