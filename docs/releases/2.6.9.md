# 言外 2.6.9 · 修复重复分析

- 修复页面前文加载范围变化后，已完成的情绪分析无法命中本地缓存的问题，覆盖重新进入聊天、内存快照淘汰和重启 wx。
- 能精确匹配的旧缓存会自动迁移，保留原分析依据；迁移写入失败时仍可显示已读到的结果。
- 继续按账号、联系人、消息内容及时间、背景和模型配置隔离，失败或未完成的分析不作为成功结果保存。

版本码 63。升级后彻底退出并重新打开 wx。无法匹配的旧缓存首次可能重新分析一次；账号无法核对或缓存连接失败时仍可能重复分析，需结合反馈机型日志确认。实机验收：等一条消息分析完成，退出再进入、切换联系人后返回、重启 wx 后检查同一条消息是否复用结果。
