# 1.8.2 · 手动填写对方身份

- 将「其他关系」改为「自定义身份」。选择后直接展开输入框，可填写前同事、相亲对象等，最多 40 字；空白时提示先填写。
- 生成回复和找话题都会使用填写的身份。选择按钮及成功结果显示实际称呼，重新打开成功建议时恢复。
- 修改自定义身份后不复用旧回复或缓存话题；切回预设身份忽略隐藏的自定义文字。输入只作为关系背景传入，不混入系统指令。
