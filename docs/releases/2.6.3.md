# 言外 2.6.3 · 把背景记下来，让下一句更好开口

这次把最近几轮更新整理到一起：聊天里的入口更集中，对方的身份与背景可以保存，分析和回复也能分别配置。

## 最近新增了什么

- **展开「＋」就能找到。** 横条左侧是当前聊天的分析开关，右侧是「帮我回 · 找话题」。不需要先打开自动分析，也可以手动生成回复。
- **身份与背景，可以单独保存。** 私聊选择自定义身份，填入对方身份和长期背景，点「保存身份」即可，不必先生成回复。「这次想委婉拒绝」等临时要求另填，不与长期背景混在一起。
- **常用角色，集中管理。** 在言外「回复」页添加、搜索、编辑和删除角色，也能管理聊天里已经保存的资料。在微信中主动选择角色后，才会用于当前联系人。
- **分析与回复，按需要配置。** 分析支持决策模型（JEV）与智能模型（LLM）；JEV 给出情绪概率，纯 LLM 给出文字判断。模型连接统一管理，支持纯 LLM 分析复用回复模型。
- **回复抽屉更高。** 身份、参考条数、背景和本次要求有更充足的展示空间。回复与话题继续由你主动生成，复制后自行粘贴发送。

以上功能来自 2.3.0～2.6.2；**2.6.3 整理实机宣传素材、更新说明与交付包，不新增分析或回复逻辑**。

## 安装与升级

1. 安装附件 `yanwai-2.6.3-debug.apk`。这是已签名的 Debug 试用包，包名 `dev.jev.wechatmood`，版本码 57。
2. 需要 Android 9+、可用的 LSPosed / Xposed 环境，并启用微信作用域。仅安装 APK 不会自动生效。
3. 从桌面打开言外，按需要配置自己的模型接口和 API Key。
4. 升级后彻底退出并重新打开微信，再展开聊天「＋」使用。

同签名旧包可覆盖安装；如系统提示签名不一致，请先核对旧包来源，不要直接卸载，以免丢失本地配置与背景资料。

言外免费开源；模型服务按你自己的账户计费。分析与生成时，相关聊天和背景会发送到你配置的服务。所有判断仅供参考，言外不会自动发送微信消息。
