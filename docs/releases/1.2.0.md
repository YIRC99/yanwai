# 言外 1.2.0

这次更新集中改善设置页、运行状态与故障排查。

- 设置页重新设计：首屏展示使用概览和下一步操作，模型连接与微信运行记录分开呈现，适配浅色与深色。
- 明确区分未保存、检测中、通过、失败、分析暂停和结果隐藏；Key 获取与微信启用步骤按需展开。
- 微信内与桌面均可导出运行日志。保存、跳转失败显示具体原因，近期日志保留到重启后，关键错误和恢复过程同步到 LSP。
- 保留多渠道模型配置、Key 申请指引及 GitHub 新版本提醒。
- 页面底部新增作者微信二维码、微信号 `YIRC99`、一键复制和开源项目入口。

言外完全免费，没有会员或付费解锁。第三方模型服务可能按其规则收费，费用不属于言外。

开源地址：https://github.com/YIRC99/yanwai

覆盖安装后打开一次言外，并彻底关闭、重新打开微信，让微信加载新版本模块。

用户此前遇到的偶发设置服务不可见已有诊断记录，仍需要故障时的连续日志定位；本版不宣称所有微信版本与系统环境均已兼容。
