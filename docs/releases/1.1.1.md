# 言外 1.1.1｜多渠道接入与后台运行修复

## 更新内容

- **新增 Jev 多渠道接入**：支持 Jev 官方、OpenRouter、Vercel AI Gateway，以及自定义 Jev 兼容接口。选择预设渠道后自动匹配地址和模型，使用该渠道的 Key 即可配置。
- **新增 Key 申请教程**：设置页提供简单的申请步骤、注册入口和官方文档，方便第一次使用的用户完成配置。
- **各渠道独立保存 Key**：切换渠道时保留各自配置，避免混用或丢失原有 Key。
- **修复划掉言外后功能失效**：微信已加载设置后，无需让言外一直留在最近任务列表中；该场景已由用户实机确认可用。
- **完善设置同步**：关闭分析、清空 Key 或切换渠道后同步更新，避免延迟到达的旧设置覆盖新配置。

## 升级提示

1. 覆盖安装新版 APK。
2. 打开一次「言外」，确认渠道和 Key。
3. 彻底退出并重新打开微信，让新版模块生效。

OpenRouter 已完成真实接口验证；Vercel 已按官方文档接入，需按平台要求完成绑卡验证，当前测试账户尚未完成成功推理验证。自定义接口须兼容 Jev 协议，普通 OpenAI 聊天接口不能直接使用。

微信自身被杀或手机重启后仍需重新读取设置，若连接失败，打开一次言外即可重试。
