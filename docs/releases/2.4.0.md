# 2.4.0 · 设置页面重新整理

本次只调整独立 APP 的界面、导航和配置反馈，聊天分析、回复生成、历史读取及缓存协议保持原有实现。

- 底部固定「首页 / 分析 / 回复 / 更多」，切换保留当前输入和各页滚动位置；子页按返回键先回首页。
- 首页集中功能入口、微信运行记录和使用指南。指南涵盖自动分析、单条解读、回复、话题、对方背景和参考消息。
- 分析来源、LLM 配置来源、意图方式改为原生下拉。只展示当前方式需要的表单，已配置的 JEV 默认收起。复用回复模型时可直接跳转回复设置，修改后返回不丢失分析页草稿。
- 卡片显示开关统一放在「更多」，立即保存；排查、更新、作者和开源许可也集中在这里。作者二维码及开源介绍默认折叠。
- 绿色表示成功，琥珀色表示待处理或未保存，红色表示失败，蓝色表示进行中；均配文字，适配系统浅深色。
- JEV、分析 LLM、回复 LLM 分别显示检测状态。JEV 按钮只检测 JEV；保存不冒充连接通过，历史运行记录不冒充微信在线。

手机验收：安装后检查四个入口、下拉切换、跨页保留输入、三个显示开关，以及浅深色和大字体。此次未操作手机 UI、未调用真实模型、未推送或发布。
