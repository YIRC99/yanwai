# 1.6.0 · 先选身份，再分条回复

- 「帮我回」首次打开也不自动生成。先选择对方身份、填写可选补充想法，再点击生成。
- 支持暗恋、暧昧、恋人、朋友、长辈、弟弟妹妹、其他家人、同事等，也可不指定。按身份选取狗头军师已有资料并调整说话分寸，完整原始资料与许可继续随应用打包。
- 模型输出 1–6 条连续短消息，通常 1–3 条；按语意组织，语气词贴合聊天习惯，不机械拆句或强加亲密称呼。
- 回复逐条点选、复制、填入，用户手动发送。填入后重开选中下一条，上一条未发出或清空时阻止覆盖；撤销成功回选原条。更换身份不会把旧建议改标为新身份。
- 初次抽屉更紧凑，身份和想法在生成按钮之前，理由按需展开；保留上下文证据、重写、旧建议恢复和草稿保护。
