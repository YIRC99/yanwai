# 意图解读悬浮窗

## 行为

- 情绪与意图分析结果改为微信当前窗口内的单个 `PopupWindow`，不再向微信的消息行插入子视图或修改原气泡 ID。
- 不申请系统悬浮窗权限，不跨应用常驻。标题栏可拖动，右侧提供 48dp 点击区域的关闭按钮。
- 长内容可滚动，正文区域最多占宿主窗口高度的一半。百分比继承正文前景色，浅色不透明背景搭配深色正文与标签。
- 同一结果关闭后不会因周期扫描或分析完成而立即重弹；长按消息再次选择“翻译意图”可以显式重新打开。
- 已有结果显示时，自动扫描到的其他消息不会抢占当前窗口。需要查看这些消息时手动选择“翻译意图”。
- 消息行回收不关闭浮窗；离开聊天、配置/账号切换导致原有 `clearAll()` 调用、宿主窗口销毁时关闭浮窗。
- 分析失败时仍可点击正文重试，保持现有分析设置和内容格式。

## 范围

只涉及结果展示及手动重新打开入口，不修改分析模型、后台服务、无障碍权限、回复生成和持久化缓存。
关闭记录为进程内有界集合（256 个键），不是永久屏蔽；微信进程重启或记录淘汰后可再次自动显示。

## 验证

新增 `AnalysisPopupStateTest` 覆盖关闭抑制、同一结果更新、其他结果不抢占、手动重新打开、有界保留和前景/背景对比度。

本次按贡献者要求只提交源码，不生成 APK，未执行完整 Android Debug 构建或设备 UI 测试。
独立 Kotlin/JUnit 执行新增的 5 项测试通过；浮窗相关源码使用 Android 接口库及项目依赖声明桩进行独立类型检查通过（不等同于完整项目构建）。
合并前建议在维护者构建环境运行单元测试和 Debug 构建，并按下面清单进行设备验收：

1. 普通文字、语音和部分分析结果逐步更新。
2. 关闭后等待扫描/分析完成不重弹，手动再次选择可重开。
3. 自动分析多条消息时不来回切换窗口。
4. 拖动、长内容滚动、大字体、横屏和分屏。
5. 离开聊天、切换联系人/账号、返回历史消息，不显示其他联系人的旧结果。
6. 分析失败时点击正文重试。
7. 微信原消息行尺寸、滚动和长按菜单不受影响。
