# 单条消息翻译意图

在微信中长按对方的纯文字消息，选择带对话气泡图标的「翻译意图」，结果沿用消息下方的分析卡，不新增结果弹窗，不改变当前聊天的开关。

## 使用规则

- 开关关闭时，只有明确选中的消息会分析、显示。可以选择多条；其他消息、新收到的消息保持不分析。
- 支持私聊及群聊中对方发来的纯文字，沿用 1000 字符与最多 10 条前文的限制；图片、语音、引用卡片、自己的消息不增加入口。
- 重复选择复用已有结果；失败可以点击卡片重试。未配置模型时，卡片提示配置或连接问题。
- 手动选择与结果仅在内存中保留，切换聊天和滚动回来可以恢复；重启微信后清空。会话自动分析开关仍独立持久化。
- 主动关闭右上角开关会隐藏当前聊天的全部卡片，并清除这个聊天的手动选择；其他聊天不受影响。关闭后仍可重新长按某条消息进行单独分析。

## 实现边界

- 通过微信菜单创建/选中方法的日志特征定位扩展入口，使用原生带图标菜单接口，不替换微信消息的长按监听器。
- 菜单项绑定实际按下的 View 弱引用及消息身份。点击时重新读取当前聊天与消息，拒绝已换聊天、已回收或已重新绑定的条目。
- 单条选择按会话、消息 ID、说话人及正文区分，保存首次选择的完整分析输入，避免加载历史后上下文变化导致重复请求和结果丢失。
- 请求排队、第二轮、气泡绘制共同使用“会话自动开启或该条被手动选择”的判定，仍要求有效模型设置以及消息当前可见。
- 菜单适配失败时不影响原有自动分析，日志包含 `MESSAGE_MENU_HOOK_FAILED`；菜单创建、点击、收尾分别记录独立错误码。连接成功记录 `MESSAGE_MENU_READY`，这不等于真机菜单验收通过。

## 手机验收

1. 关闭聊天 A 的开关，长按一条对方文字，确认原菜单仍有复制/转发等选项，并新增图标和「翻译意图」。
2. 选择后只在该条消息下面显示“正在分析”和最终结果；开关仍关闭，其他消息和新收到的消息不出现分析卡。
3. 再选另一条，两条结果同时保留；重复选择已有结果不重复请求。分析失败时点击卡片可以重试。
4. 滚动离开再回来、进入聊天 B 再回 A，确认结果没有串到其他消息，A 的手动结果能恢复。
5. 打开再关闭 A 的自动分析，确认全部卡片消失，包括之前手动选中的消息；切换聊天或滚动回来也不恢复。B 的开关和手动结果不受影响。再次长按 A 的某条消息可只显示该条分析。
6. 在群聊、深色模式下检查菜单与卡片；长按图片、语音、自己的消息不出现本入口。打开菜单后取消，再长按另一条，确认目标正确。
7. 重新启动微信，确认手动卡片清空，原来的会话开关记忆仍保留。

微信菜单及布局会随版本变化。离线单测、编译和 lint 不能替代以上手机验收；本次不主动操作手机或启动应用。
