# 运行日志与跨进程设置排查

## 用户导出方法（1.1.3）

- 微信聊天页：长按右上角「绘制」→「导出运行日志」→「保存日志文件」。
- 微信设置页：长按底部「言外」入口。即使点击入口不能跳转，也能查看和导出微信进程里的日志。
- 开关保存或设置跳转失败：错误对话框直接提供「导出运行日志」「复制诊断」。
- 桌面言外：「展开排查信息」→「导出运行日志文件」或「复制运行日志」。

Android 10+ 保存到下载目录 `Download/Yanwai/yanwai-wechat-时间.txt` 或 `yanwai-app-时间.txt`，成功后可点分享文件。Android 9 使用完整文本复制。文件保存、分享或复制受系统限制时，会提供错误提示和可选择的日志正文；不申请广泛存储权限。

微信与言外分属不同进程和私有目录。微信内导出直接读取微信本地日志，不依赖设置 Provider，不需要桌面言外运行。桌面导出包含本进程日志，以及微信通过已有受 UID 限制的 Provider 最近上报的日志片段（48K 字符，最多每 15 秒随状态变化附带一次）。没有收到时明确标注缺失；收到的记录注明时间，不能当作实时状态。需要完整微信日志时，应在微信内导出。

日志按进程持久化并保留最近 128K 字符（最多约 512KB UTF-8）。文件写入失败时保留内存副本，明确提示需在关闭进程前导出。关键警告、错误堆栈及启动信息另写入 LSP 日志。若模块完全没有加载，仍需 LSPosed 自身日志；存储耗尽、进程被杀或系统禁止所有导出方式时不能保证完整记录。

不主动记录聊天正文、完整配置或 HTTP 请求/响应体；导出保留错误码、堆栈、Android/微信/模块版本、包可见性、进程 UID/用户空间及开关状态。已加载的 API Key、常见认证字段和 Bearer 值脱敏。用户分享前仍可查看日志。

## 为什么桌面打开后能用，重启后又失效

设置保存会由言外向运行中的微信发送受签名权限保护的配置广播。微信把可信配置留在内存；这条推送通路可用并不意味着微信能反向访问言外 Provider。聊天开关保存必须调用 Provider 并核对回执；微信重启则需要首次读取 Provider。后两条被阻断时，就会出现本次症状。该解释由代码链路支持，实际广播送达需要新日志验证。

1.1.3 不绕过应用隐藏规则，不在微信磁盘缓存 API Key，也不把临时状态冒充保存成功。增加异常记录、明确失败回执校验、恢复日志及独立导出入口。
